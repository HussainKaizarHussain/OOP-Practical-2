# OOP-Practical-2: Classes, Access Specifiers and Member Functions

## Purpose & Aim
- **Aim**: To understand how classes combine data and behaviour, and how access specifiers protect data[cite: 1].
- **Question**: Design and implement a class hierarchy or class model for a real-world entity, such as BankAccount or Vehicle[cite: 1].

---

## What to Do
- Create a class such as BankAccount with suitable private data members, for example account number and balance[cite: 1].
- Add public member functions to set or display details and perform a meaningful operation such as deposit or withdraw[cite: 1].
- Use a constructor to initialise the object and validate values where needed[cite: 1].
- Explain in comments which members are private and which are public, and why[cite: 1].
- Create at least two objects and demonstrate their member functions from main()[cite: 1].
